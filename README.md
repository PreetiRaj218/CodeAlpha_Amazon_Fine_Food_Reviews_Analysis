# Amazon Fine Food Reviews Analysis

## Project Overview
This project analyzes the Amazon Fine Food Reviews dataset using Python.

## Tasks Completed
- Exploratory Data Analysis (EDA)
- Data Visualization
- Sentiment Analysis

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- NLTK

## Key Findings
- Most customers gave 5-star ratings.
- Positive reviews dominate the dataset.
- Customer sentiment is generally positive.

## Dataset
Amazon Fine Food Reviews Dataset
